# Contributing to RMI

We welcome contributions! Here's how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch: `git checkout -b feat/my-feature`
4. Make your changes
5. Run tests: `pytest -p no:pytest-brownie`
6. Push and open a PR

## Standards

- Conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`
- Python: ruff + mypy strict — all code must pass
- TypeScript: prettier + tsc — no any types
- Tests required for new features
- AI agents read AGENTS.md + CONVENTIONS.md first

## PR Checklist

- [ ] Lint passes (ruff / prettier)
- [ ] Type checks pass (mypy / tsc)
- [ ] Tests pass
- [ ] Documentation updated
- [ ] Conventional commit format

# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security issue in any RMI project, please report it privately.

**DO NOT** create a public GitHub issue for security vulnerabilities.

Email: biz@rugmunch.io

We will acknowledge receipt within 48 hours and provide a timeline for resolution.

## Responsible Disclosure

We ask that you:
- Allow us reasonable time to fix the issue before disclosure
- Do not exploit the vulnerability
- Do not publicly disclose until we've resolved it

## Scope

In-scope: All repositories under github.com/Rug-Munch-Media-LLC
Out-of-scope: Third-party dependencies, infrastructure not owned by Rug Munch Media LLC

## Recognition

We maintain a hall of fame for researchers who report valid security issues.
